# lavapipe's differences from the counts table (M5 X4): the rows where CI's lane, on lavapipe on x86-64 Linux,
# counts differently from tests/counts/district-ci.txt, which an M5's Metal (aarch64) takes. The lane holds each
# walk to the table's figure plus the difference below (`sapphire_testkit counts --differences`); every other row
# to the table's. A line naming a walk or row the table doesn't hold, a difference of zero, or a line with no
# reason above it fails, so the file can't rot (sapphire_testkit::counts::differences).
#
# Until M6 X4 nearly every row here was the crowd's: the tour walks the avenue on x = 0, a cell edge, where the
# eye's x was a residue of -1.6e-6 on an M5 and not negative on x86-64, and the crowd took the focus's own cell by
# `floor`, so the two machines stood different people. Since X4 the crowd reads a place to 1/256 m before taking
# its cell and keeps its own cell until the focus is 2 m past an edge (sapphire_stage/src/scene/ambient.rs,
# `CELL_READING` and `CELL_MARGIN`), so both stand the same people, and CI's lane on lavapipe counts the table on
# every row of all four walks: this file holds no difference.
#
# A change that moves a row the same on both machines is written in the table alone. Refresh this file from CI's
# artifacts (each `scale-lane-<walk>` folder holds the run's counts.txt), walking nothing:
#   sapphire_testkit counts --table tests/counts/district-ci.txt \
#     --differences tests/counts/district-ci-vulkan-lavapipe.txt --refresh <folder>...
# It keeps each line's reason, and writes a new difference under a placeholder that fails until it has one.
